## 从零搭建 LightAgent（轻量级 AI Agent 开发平台）

**背景**：用户提供 ~20 章完整需求文档，要求在当前目录 E:/zzh 搭建可运行项目。本机无 Docker / PostgreSQL。

**技术决策**
- 后端 FastAPI + SQLAlchemy 2.x async，DATABASE_URL 适配：本地 SQLite（默认可跑），Docker 用 PostgreSQL + pgvector。
- 前端 Vue3 + TS + Vite + Naive UI + Tailwind3 + Pinia + Vue Router + Vue Flow + ECharts + Monaco，自建 LaIcon 图标组件（不引 iconify）。
- 自研 Agent Runtime（Function Calling 优先 / ReAct 兜底，步数/超时/调用次数限制）+ 自研 DAG 工作流引擎（拓扑排序 + 条件分支 + SSE 事件）。
- Provider 抽象 BaseLLMProvider；DeepSeek/OpenAI 共用 OpenAI 兼容实现。
- 统一响应信封用自定义 APIRoute（core/response.py）包装 JSON 响应，SSE 原样透传。
- 向量检索当前在应用层算余弦（document_segments.embedding 存 JSON），pgvector 仅建扩展，接口预留。

**踩过的坑**
- pydantic-settings 2.7 会对 List 字段强制 JSON 解析 .env → 改为 str 字段 + cors_origins property。
- Python 3.13 需显式装 greenlet，否则 async SQLAlchemy 报错。
- pip 直连 pypi 超时 → 使用清华镜像；npm 用 npmmirror。
- SSE 事件重复（service 与 engine 各发一次 run_started/run_completed）→ service 侧去重并合并 run_id。
- WorkflowEngine 里 asyncio 在 try 内 import 导致 except 引用未定义 → 提到模块顶层。
- vue-tsc: @vue-flow 泛型推导过深 TS2589 → nodes/edges 用 any[]；NSelect 同时 v-model 和 :value 报重复属性。
- 后台进程用 bash `&` 会随命令结束被杀，必须用 run_in_background。

**交付状态**

## 修复 /api/v1/logs/runs 500（与 dashboard 同源缺陷）

- 根因同 Dashboard：`select(Application.id).scalars().all()` 返回主键字符串，却又取 `.id` → AttributeError。
- 同时修掉：工作流分支缺工作区隔离与关键词过滤、wf_map 全表扫描、`datetime.utcnow()` 废弃写法。
- **新发现的真实问题**：SQLite 存 JSON 默认 `ensure_ascii=True`，中文成 `\u65e5\u5fd7`，
  导致 `cast(col, Text).contains('日志')` 命中 0。修法两条：
  1. `create_async_engine(..., json_serializer=lambda o: json.dumps(o, ensure_ascii=False, default=str))`；
  2. logs.py 加 `_kw_variants()`，同时匹配原文与 `\uXXXX` 转义形态，兼容历史行。
- 前端：日志页 LLM 行的「详情」按钮改为不渲染（LLM 日志无轨迹接口，点了必 404）。
- 回归测试新增 `test_logs_runs_all_types` / `test_logs_stats`，pytest **41 passed**。
